Download a hospital treatment confirmation report

This report only includes motor liability and public liability claims managed using the digital service.

This report will show:

  • how long it took to confirm the hospital treatment outcome
  • how many times these task outcomes were recorded: hospital treatment took place, hospital treatment did not take place and hospital treatment cannot be confirmed
  • at what point in the process an agent found out the hospital treatment outcome
  • when hospital treatment could not be confirmed, how often an agent recorded the injury as serious

Download report within a date range

Make sure the date range is no more than 90 days. Hospital treatment confirmation reports can only include data within this period.
